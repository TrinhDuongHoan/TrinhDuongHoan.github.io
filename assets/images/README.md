# Ảnh đại diện

Đặt ảnh đại diện của bạn trong thư mục này với tên:

```text
profile.jpg
```

Khuyến nghị:

- Ảnh vuông, tỷ lệ 1:1
- Kích thước từ 800 × 800 px trở lên
- Định dạng JPG hoặc WebP
- Dung lượng dưới 500 KB để website tải nhanh

Đường dẫn sử dụng trên website: `assets/images/profile.jpg`.
